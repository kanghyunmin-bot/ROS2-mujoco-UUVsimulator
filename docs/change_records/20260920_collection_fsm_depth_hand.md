# 자동 수집 FSM 수심·손 정렬 수정 및 검증 (2026-09-20)

## 범위

자동 수집 전용 `collection_fsm_node`와 검출기/runner를 수정했다.
기존 `mission_state_machine_node`, 카메라 장착 방향, 포크/부표 접촉 물리는 변경하지 않았다.
현재 GUI에서 다음 자동 수집 실행 시 새 실행파일을 사용한다.

## 실패 원인과 대응

1. 원본 SEARCH는 제어권 인계 시 수심을 유지했고 좌우 이동 채널을 쓰지 않았다.
   목표 수심을 0.3~2.0 m 사이에서 왕복하고 손 카메라 오차로 좌우 이동하도록 했다.
2. 전방 YOLO의 작은 노란 부표 누락과 큰 오검출이 관찰됐다.
   시뮬레이션용 노란 타원 보조 검출을 켜고 기존 목표의 연속성을 우선했다.
   화면 가장자리 목표를 제외하는 규칙은 추가하지 않았다.
3. 전방/손 검출 전환 때 수심 목표 급변과 미분항 충격이 발생했다.
   목표 변화 속도를 제한하고 실제 수심 변화로 미분항을 계산한다.
4. 작은 제어 출력이 ArduSub RC 데드존 안에 들어가 무시됐다.
   확인한 RC3/5/6=30 PWM, RC4=40 PWM 설정을 반영했다.
5. 현재 손 카메라는 기체 우측 약 48도, 아래 약 19도를 본다.
   접근은 전방 x=0.45를 선호하고, 근거리에서는 전진을 멈춰
   전방 x=0.85로 돌린 후 손 영상으로 넘긴다. 사용자가 허용한 우측 접근이다.
   손 정렬 목표는 x=0.45, y=0.60이며, 수심·좌우 오차가 크면 전진을 억제한다.

전체 설정과 기하학적 임계값은 `tools/auto_collection/README.md`에 공개했다.
이 FSM은 규칙 기반 교사이며 학습 기반 근접/분리 판정기가 아니다.

## 검증

- C++ 제어 함수/인터페이스 테스트 2개 통과.
- 노란 타원 테스트 4개 통과(작은 목표, 가장자리 목표 포함).
- 자동 수집 판정/소유권 관련 테스트 7개 통과.
- 실제 기체와 분리한 ROS_DOMAIN_ID=155에서 수심 탐색, 손 카메라 인계,
  양방향 좌우 제어, 전진 억제, 목표 변경 시 미분항 충격 방지,
  합성 입력에 대한 INSERT_FORK 전이를 확인했다.
- 원본 실행파일로 같은 검증을 실행하면 SEARCH 수심 고정 검사에서 실패한다.
  합성 입력의 삽입 전이 통과는 실제 접촉/분리 성공을 의미하지 않는다.

실제 시뮬레이션에서 v1~v5는 성공하지 못했다. v5는 120초 제한으로 실패했다.
최종 v6는 손 카메라 인계까지 진전했으나 가장자리 막대 검출 단절로
ALIGN_STICK/APPROACH_BUOY 전환이 반복된다. 실제 분리 성공률은 아직 검증되지 않았다.
실패 자료는 실패로 보존하며, 자동 학습은 실행하지 않았다.

로그: `outputs/fsm-revision/` 및
`outputs/auto-collection/gui-20260920-090240-2e6395/`.
실제 성공은 포크 접촉과 부표 구속 해제 증거를 runner에서 독립적으로 확인한다.
영상에서 안 보이는 것만으로 성공 처리하지 않는다.

최종 v6 실제 시험 결과: 120.1초, 1,203프레임, 성공 0/1,
`episode_time_limit`. 손 정렬 단계 진입은 확인했지만 INSERT_FORK에
도달하지 못했다. 녹화 저장·맵 복구를 확인했고 자동 수집 종료 및
DISARM 상태를 API로 확인했다. GUI 서버는 사용자가 계속 쓸 수 있게 유지했다.
