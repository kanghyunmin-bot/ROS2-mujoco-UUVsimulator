2. 학습 진입점의 CAP 제외 및 설정 저장

파일: tools/finetune_transfer.py
입력한 조직 U0 checkout을 import 경로에 우선 적용한다.
CAP target_loss_weight=0.0을 강제한다.
학습 runner에 전달하는 모델의 runtime 설정과 직렬화되는 설정을 모두 0으로
맞춰 저장 후 추론에서 CAP가 다시 켜지는 설정 불일치를 방지한다.
experiment_cfg/kmu26_transfer.json에 배포 규격을 남긴다.
원본 trainer를 직접 수정한 것이 아니라 로컬 실행 wrapper에서 적용한다.

3. 학습 데이터 / 체크포인트 규격 검사

추가 파일: kmu26_auv_vla_data_collector/deployment_config.py
학습 데이터의 source manifest를 확인하여 다음 규격을 요구한다.
  STABILIZE, 10 Hz, 채널 [5,6,3,4], neutral=1500, PWM span=400
  전처리: Kmu26TransferDataConfig, CAP target_loss_weight=0
기존 span=300 데이터나 다른 모드를 섞어 자동으로 재해석하지 않는다.
저장된 배포 정보 및 모델 config의 CAP-off 일치 여부를 검사한다.
실물 데이터를 이 시뮬 전용 계약으로 무조건 학습할 수 있다는 뜻은 아니다.

4. 추론 실행 도구 추가

추가 파일: tools/serve_transfer.py
체크포인트의 KMU26 상태/행동 규격 및 CAP-off 배포 정보를 먼저 검사한다.
--check_only로 GPU 모델 로딩 전 계약 검사만 수행할 수 있다.
통과한 경우 제공한 U0 checkout의 서버를 학습과 같은 transfer 전처리로 시작한다.
기본 HTTP 주소는 127.0.0.1:8000이다.
실제 모델 학습, 가짜 정책 출력, 임의 호환 가중치 생성은 하지 않았다.

5. 이번에 새로 만든 기능과 기존 기능 구분

이번에는 이 경로의 설정 불일치와 CAP 저장/추론 설정을 보완했다.

수정했으며 이 ROS 패키지의 수집 노드 전체를 새로 작성한 것은 아니다.

7. 첫 실데이터 학습 실행 준비 및 bf16 로딩 수정

outputs/vla-first-training-20260920/에 64개 원본의 구조 검사, 50개 성공 라벨
시연 검토용 이미지, 세션이 겹치지 않는 40/10 분할 및 LeRobot 변환을 저장했다.
검수 스크립트·JSON·노트북과 원본 manifest/samples 해시를 보존했다.
실패 13개와 접근 정지 테스트 1개는 학습에서 제외하고 원본을 유지한다.
50개의 성공 라벨 자체는 작업자 판단이며 듬성듬성한 영상 검토를 성공 GT로
간주하지 않는다. 변환 결과 train 4,410 / validation 1,051 프레임,
완전한 16-action chunk train 3,810 / validation 901개를 실제 U0 loader로 검사했다.
finetune_transfer.py에 --model-storage-bf16 명시적 옵션을 추가했다.
16GB GPU 메모리를 절약하며, bf16에서는 지원되지 않는 Beta/Dirichlet 샘플링은
float32로 유지하고 upstream에서 요청 dtype으로 변환하도록 했다.
실제 학습 첫 forward에서 발생한 오류 로그를 보존하고 수정 후 10단계 학습,
전체 행동 모델 학습 및 체크포인트 저장을 확인했다. 기존 호출 기본값은 유지한다.
2,000단계 본 학습과 별도 검증·시뮬 평가는 실행 로그/결과 파일을 기준으로 판단한다.

8. 첫 실제 학습 실행 및 저장 모델 검증 (2026-09-20)
- 고정한 성공 시연 50개를 세션 단위로 학습 40개 / 검증 10개로 분리.
- 원본 보존, CAP 제외, 상태 23차원 / 행동 4차원, 10 Hz.
- U0 사전학습 가중치에서 projector + DiT를 2000 step fine-tuning.
- RTX 5080 16GB: bf16 모델 저장, batch 1; 실행 264.86초. 시각/언어 백본 고정.
- bf16 Beta 샘플링 미지원: 분포 파라미터만 float32로 유지하고 기존 모델 흐름에서 변환.
- 최종 저장 모델을 다시 읽어 검증 40개 관측의 16-step 출력 비교.
  MSE 0.08732, MAE 0.16205, 중립 행동 기준 MSE 0.15742.
  이 결과는 오프라인 행동 모방 지표이며 임무 성공률이 아님.
- HTTP 출력은 원래 U0의 [actions, null] envelope를 유지.
- 모델 연속 출력의 정규화 범위 초과는 서버에서 [-1,1] 포화 처리하고 로그에 기록.
  비유한 값, 잘못된 shape 및 CAP target은 거부. ROS 입력 계약의 엄격성은 유지.
- 결과: outputs/vla-first-training-20260920/ (model/, split.json, eval-first.json 등).
