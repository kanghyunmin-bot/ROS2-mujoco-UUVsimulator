다음 VLA 학습 개선 메모
작성일: 2026-09-20
상태: 사용자 요청 기록. 현재 모델/학습 설정에는 아직 반영하지 않음.

1. 목표물 미관측 시 탐색 강조
- 전방 카메라 또는 손 카메라에서 목표가 보이지 않는 상황에서 주변을 탐색하는 동작을 강조한다.
- 구현 시 한 카메라에서만 사라진 경우와 양쪽 모두에서 사라진 경우를 구분한다.
  다른 카메라에서 목표를 추적할 수 있다면 불필요한 탐색 대신 해당 관측을 활용한다.
- 구체적인 탐색 동작, 미관측 지속 시간 및 강조율은 추후 결정한다.

2. 접근 이후 손 카메라 중심의 정밀 정렬
- 접근 중 전방 카메라에서 목표가 일정 이상 가까워지면 손 카메라의 작업 영역을 더 중요하게 활용한다.
- 목표는 노란 부표 하부 봉을 고정 갈퀴/포크에 확실히 끼우는 것이다.
- 근접 판정 기준과 카메라 중요도 전환 방식은 추후 결정한다.
- 영상상 크기나 근접만으로 실제 봉 끼움/접촉을 확정하지 않는다.

학습 설계 시 주의
- 현재 구간 샘플링 강조는 카메라별 모델 attention을 직접 제어하는 기능과 다르다.
- 탐색 및 봉 정렬 행동을 학습하려면 해당 행동을 포함한 시연 구간과 검증 기준이 필요하다.
- CAP 없는 기본 실험 조건을 유지한다.
