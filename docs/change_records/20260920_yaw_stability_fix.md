# Yaw 안정화 수정 — 2026-09-20

## 변경 내용

- 리셋 중 FCU 센서 전송도 매 물리 tick에 실행한다. 일반 ROS 화면 갱신 주기로 제한되던 결함을 수정했다.
- 별도 `research_pool_yaw_stable` 환경에서 SITL 전용 yaw 제동을 사용한다. 스틱을 놓고 250ms가 지났다는 이유만으로 이전 방향으로 되돌리지 않고, 회전 속도가 0.2°/s 아래로 내려온 뒤 현재 방향을 유지한다. 입력 해제와 방향 포착 때 이전 적분값을 제거한다.
- STABILIZE와 ALT_HOLD가 같은 초기화 함수를 사용한다. 실기체 빌드에는 포함하지 않으며, 이전 환경은 해당 기능을 비활성화한다.
- SITL의 자기장 센서를 사용해 방향을 관측한다. 완벽한 정답 자세를 FCU에 대신 넣는 AHRS 설정은 사용하지 않는다.
- 별도 물리 파일에 저속 yaw 점성 저항 0.8 N·m·s/rad를 둔다. 실측 실기체 계수가 아닌 시뮬레이터 안정화 조정이다. 기존 물리 파일은 보존한다.
- 기존 낮은 관성의 시뮬레이터에 과도했던 roll/pitch 제어값을 새 환경에서만 조정한다. 중간 후보에서는 작은 yaw 입력이 안정적이어도 최대 입력 후 roll 진동이 발생했으므로 채택하지 않았다.
- yaw 적분 제어는 0으로 유지한다. 적분을 높인 후보는 큰 입력 해제 후 반대 회전과 왕복 진동을 만들어 제외했다. 최종 계수는 `config/ardusub_yaw_stable.param`에 모았다.

## 데이터 구분

기존 18개 에피소드와 5,000스텝 모델은 변경하지 않는다. 새 환경의 녹화에는
`yaw-stable-20260920-v1` 제어 설정 식별자를 포함해 기존 카메라 버킷과 분리한다.
녹화 메타데이터에 물리 파일과 제어 계수 파일의 증거를 함께 저장한다.

## 검증 방법과 범위

- 격리된 ROS 영역과 진단 컨테이너에서 실제 MuJoCo + ArduSub + MAVROS를 실행했다.
- 실제 몸체 각속도, RC 입력/출력, FCU 파라미터와 DataFlash 주기 로그를 기록한다.
- 좌우 약한 입력, 중간 입력, 최대 입력을 각 2초 적용하고 12초씩 중립을 관찰한다.
- 카메라 두 개를 구독해 실제 영상 생성 부하를 포함한다.
- 리셋 3회와 디스암 후 정지 상태를 관찰한다. 최종 시험은 GUI와 같은 추진기 100Hz를 사용한다.
- 합격 기준은 역회전 최고 1°/s 이하, 해제 7~12초 구간 평균 절대 각속도 0.2°/s 이하, 안정 후 20초 동안 실제 방향 변화와 표시 변화의 차이 2° 이하이다. 완벽한 0이나 모든 환경에서의 보장을 의미하지 않는다.
- 디스암 후 위치 보조 없는 EKF가 재초기화될 때 방향 표시가 일시적으로 바뀌는 현상을 별도로 기록했다. 해당 순간 실제 기체는 회전하지 않았다. 최종 시험은 관찰을 60초로 늘려 재정렬 이후의 마지막 20초를 비교하며, 재초기화 사건을 숨기거나 삭제하지 않는다.

원시 기록과 불합격 후보는 `outputs/yaw-diagnosis-20260920/`, 최종 집계와 재현 도구는
`outputs/yaw-fix-20260920/`에 보관한다. 부표 접촉, 다른 PC 부하 및 실기체까지의 보장은 이 시험 범위에 포함되지 않는다.

## 다른 설치에 적용

`setup/patch_ardusub_yaw_braking.py --apply`로 해당 ArduSub 소스에 패치를 적용하고 SITL을 다시 빌드한다.
새 환경은 패치 표식 없는 오래된 실행 파일을 발견하면 시작을 거절하고 적용 안내를 표시한다.
이전 환경 선택은 계속 사용할 수 있다.

## 최종 측정

실제 수조 장면, 두 카메라, 추진기 100Hz에서 STABILIZE 6회와 ALT_HOLD 4회를 시험했다.
약한·중간·최대 좌우 입력을 포함한 10회 모두 동작 기준을 통과했다. 해제 후 10초 내
역회전 최고치는 0.236°/s, 해제 7~12초 평균 절대 각속도의 최악값은 0.124°/s였다.
STABILIZE 6회에서는 측정한 역회전이 0이었다. 최종 yaw P는 0.7, I는 0이다.

정지가 순간적인 것은 아니다. 같은 1600 PWM 비교에서 해제 후 최대 진행각이
기존 약 13.17°에서 약 17.23°로 늘었다. 역회전으로 원래 방향에 되돌아가던 동작을
없애면서 생긴 절충이다. 0.49 후보의 실제 수조 ALT_HOLD 약 21.35°보다 최종 0.7의
약 17.09°가 작지만, 기존보다 더 짧게 정지한다고 주장하지 않는다.

모드 전환 직후 첫 리셋 요청은 브리지 상태가 아직 ALT_HOLD여서 거절됐다. 해당 요청을
성공 횟수에 포함하지 않았다. STABILIZE 확인 후 별도 `stable_final_reset` 시험에서
3회 모두 성공했고, FCU 긴 루프는 0회, 최대 루프 시간은 2.5ms였다. 시험 도구는 이후
리셋 응답 성공 여부를 명시적으로 기록·검증하고 모드 전환 후 갱신을 기다린다.

디스암 후 재정렬이 끝난 마지막 20초의 실제 방향 변화와 표시 변화의 차이는 0.236°였다.
재정렬 중 일시적인 표시 변화는 남아 있으며 실제 기체 회전과 구별해야 한다.

회귀/GUI 테스트: 45 passed, 1 skipped, 13 subtests passed. 별도 GUI 입력 테스트 3개 통과.
배포용 펌웨어 패치를 원본 파일에 적용한 뒤 현재 소스와 바이트 단위로 일치함을 확인했다.
