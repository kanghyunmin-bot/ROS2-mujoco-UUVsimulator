# 리서치 풀 맵과 위치 편집

리서치 풀은 내부 10 × 5 m, 수심 5 m이며 수면은 Z=0, 바닥은 Z=-5 m이다.
벽과 바닥에 타일 무늬를 넣고 기존 SLAM 장애물과 대회 표식은 제거했다.
기존 테스트 수조의 바닥 고정 부표 모델 3개를 재사용했다. 초기 부표 수심은 3 m이다.

1. 웹 GUI의 Environment / physics에서 Research pool 계열 환경을 선택한다.
2. `맵 · 위치 편집`을 연다. Mode는 `리서치 풀 · 10 × 5 × 5 m`이다.
3. 로봇 또는 부표를 평면도에서 드래그하거나 목록에서 선택하고 X, Y, 수심을 입력한다.
4. `배치 저장`은 다음 실행에 반영한다. `저장 후 시뮬레이션 재시작`은 저장한 연구용 풀로 재시작한다.

수심은 아래 방향의 양수이다. 부표 수심을 바꾸면 바닥 고정부의 수평 위치,
지지대 높이와 부표 고정 제약도 함께 변경된다. 벽/바닥 밖의 좌표는 제한한다.
물체 사이의 겹침은 자동으로 해소하지 않으므로 서로 겹치지 않게 배치한다.
편집 내용은 `uuv_mujoco/current/scenes/research_pool_slam_scene.xml`에 저장하며 기존 파일을 백업한다.
기존 파일명과 환경 ID를 유지하므로 기존 실행 명령을 그대로 쓸 수 있다.

맵 로드, 배치 저장/재로드, 잘못된 좌표의 일괄 저장 거부, 변경된 지지대와
고정 제약, MuJoCo 내 부표 유지 및 유체 적용 단기 실행을 확인했다.
실물 로봇과 VLA 주행 검증은 이 맵/GUI 작업 범위에 포함하지 않았다.

기존 웹 GUI 공통 검사 15개 중 13개 통과, 핑거 기본값과 미션 실행 검사 2개는
이전부터 알려진 실패 상태이다. 이번 맵 편집의 전용 검사 3개와 장면/물리 검사는 통과했다.

## 몸체 접촉과 부표 분리

리서치 풀은 실제 로봇 몸체가 부표에 접촉하면 바닥 고정을 해제한다.
근접만으로는 해제하지 않으며 고정 해제 후 기존 부력·항력·수면 처리를 사용한다.
수심 3 m 시험에서 약 10초 후 수면에 도달했고 비접촉 부표는 고정 상태를 유지했다.
실제 자석 분리 하중을 측정한 모델은 아니며 현재는 접촉 즉시 분리하는 시뮬레이션 규칙이다.
초기 배치는 시뮬레이션 재시작으로 복원한다. 다른 대회 맵의 갈퀴 접촉 규칙은 유지한다.
