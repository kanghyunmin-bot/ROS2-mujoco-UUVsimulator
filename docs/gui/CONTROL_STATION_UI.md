# Control Station UI — 2026-09-14

## 실제 화면에서 확인한 문제와 변경

1. **기본 화면**: 둥근 카드·민트 버튼·큰 여백을 각진 2–3px 패널, 얇은 테두리, 작은 숫자 타이포그래피, Ice Blue 강조색으로 통일. 기존 카메라/조종/설정 기능을 유지했다.
2. **물리·맵 설정창**: 흰 숫자 입력칸과 밝은 배경으로 생기던 대비 문제를 수정. 긴 설정창의 제목/닫기/하단 동작을 고정하고 숫자 입력에 접근성 이름을 부여했다. 실제 파일 적용/시뮬 재시작 버튼은 시험 중 누르지 않았다.
3. **창 열기·닫기**: 공통 창 관리자로 Esc, Tab 순환, 배경 입력 차단, 호출 버튼 포커스 복귀를 처리. Raw JSON 같은 중첩 창은 닫으면 부모 창으로 돌아간다. 배경 클릭으로 편집창이 예기치 않게 닫히지 않는다. 닫기는 파일 저장 명령을 보내지 않는다.
4. **센서 표시**: null/빈 값을 숫자 0으로 처리하던 결함을 수정. 미수신 자세·수심에는 NO DATA, 실제 0에는 0을 표시한다. 수신 경과시간을 제공하고 2초 초과 계기판에는 STALE 문구를 붙인다. 2초는 화면 안내 기준이며 수집기 유효성 계약을 변경하지 않는다. 속도를 임의로 DVL 값이라고 부르지 않고 기존 소스 이름을 표시한다.
5. **카메라 확대**: 별도 화면에서 기존 영상/조종 DOM을 재사용. 닫으면 두 패널의 원래 위치와 포커스를 복원한다. 기존 카메라 토픽·영상 변환·조종 주기는 유지했다.
6. **VLA**: 상단 `VLA 수집` 또는 중앙 `VLA 수집 창 열기`로 독립된 앱 내부 창을 연다. 작업 지시문, 모드, 전방/손/IMU/수심/RC/운용 조건/시계 체크, 녹화와 결과를 모았다. 창 닫기는 녹화를 종료하지 않으며 녹화 상태는 상단에 남는다. 저장/폐기 후 `세션 종료`로 지시문이나 모드를 바꿀 수 있다.

## 확인 결과

- 실제 브라우저에서 위 기본 화면, 물리 설정, 맵 설정, 카메라 확대, VLA 창을 열어 확인했다.
- Raw JSON → Esc → 물리 설정 복귀와 확대 종료 후 원위치 복구를 확인했다.
- VLA 창의 마지막 키보드 항목에서 Tab을 누르면 닫기 버튼으로 돌아가는 것을 확인했다.
- 화면 폭 1134px에서 가로 넘침 없음. 다른 화면 크기는 CSS 대응을 넣었으나 이번 실행에서 모두 실측 검증한 것은 아니다.
- GUI 버튼으로 실제 ROS 수집기를 준비하고 상태를 수신했다. 센서가 없는 상태에서 시작 버튼이 차단됐으며, 세션 종료 후 프로세스가 멈추고 새 설정 입력이 가능함을 확인했다.
- 관련 수집기/GUI 시험 23개 통과. 기존 핑거/미션 계약 시험 2개는 이전 실패로 별도 관리하고 이번 대상 실행에서는 제외했다.
- `test_web_sensor_display.cjs`: 수정 전 null→0에서 실패하고 수정 후 통과.
- 새 프런트엔드 패키지·원격 폰트·WebGL·상시 애니메이션을 추가하지 않았다. blur는 헤더와 열린 창 표면에만 제한했다. 실제 FPS/CPU 개선율은 측정하지 않았다.

시뮬레이션은 정지 상태였다. 이번 GUI 점검은 실시간 영상 스트리밍·물리 조종·유효한 작업 시연을 검증한 것이 아니다. Ping360의 실제 스캔 시각화는 기존 RViz/rqt 뷰어를 사용하며, 이 변경에서 새 소나 렌더러를 만들지 않았다.

## 재현

1. `./run_control_gui.sh --web --host 127.0.0.1 --port 8878`로 GUI를 실행한다(기존 ROS/컨테이너 환경 사용).
2. 브라우저를 새로고침한다. 물리 설정/맵/카메라 확대/VLA 창을 열고 Esc·Tab·닫기를 확인한다.
3. VLA 창에서 레코더 준비를 누른다. 센서가 없으면 녹화 시작은 차단되어야 한다. 대기 상태에서 세션 종료가 가능해야 한다.
4. `node uuv_mujoco/current/tools/test_web_sensor_display.cjs`로 결측/실제 0 표시를 확인한다.

이전 미커밋 물리·시작 자세·충돌 변경은 보존했다. 이번 디자인 변경은 `web_static`의 스타일·창/센서/수집 화면과 레코더의 대기 세션 종료에 집중했다.
