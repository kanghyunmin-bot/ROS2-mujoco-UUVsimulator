# 손 카메라

다운로드 영상 `yolo_0807_213821_3cam_montage.mp4`의 세 번째 화면,
IMX219 camera1을 참고했다. 가운데 camera0의 탑뷰는 구현하지 않았다.

리서치 풀의 `stereo_right`는 기존 정면 평행 시점에서 손을 비스듬히 보는 시점으로 변경했다.
기존 이름과 `/stereo/right/image_raw` 별칭은 유지한다.
실물과 같은 `/imx219/camera1/image_raw`, `/compressed`, `/camera_info`로 발행하며,
ROS optical TF도 렌더 카메라의 회전에 맞춘다.
GUI에서는 RGB 정면 영상과 IMX219 camera1 손 영상을 별도로 표시한다.
GUI 오른쪽 입력을 별도로 지정한 사용자는 `--right-image-topic` 설정을 확인한다.

카메라 위치는 로봇 기준 (0.34, 0.06, 0.025) m,
로봇 오른쪽(-Y)을 향하며 시선 목표는 (0.53, -0.18, -0.075) m, 수직 화각은 82도이다.
이는 영상 기반 근사치이며 실측 외부 파라미터나 렌즈 보정 결과가 아니다.
손 형상은 추가하지 않았다. 기존 로봇 형상에 두 카메라의 위치와 방향만 적용했다.
정면 렌즈는 몸체 내부 가림을 피하도록 로봇 기준 (0.34, 0, 0.06) m에 배치했다.
다른 환경의 카메라 배치는 이번 변경에 포함하지 않는다.

기존 camera0 발행 별칭은 여전히 정면 영상을 복제한다. 이를 실제 탑뷰 데이터로
간주해서는 안 된다. 이번에 손 영상으로 바뀐 camera1을 사용하는 VLA 데이터는
기존 정면 두 시점 데이터와 관측 구성이 다르므로 구분해서 수집해야 한다.
