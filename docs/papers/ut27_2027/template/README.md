# IEEE A4 template provenance

Rules: [UT27 Authors](https://ut27.org/authors.html), checked 2026-09-15.

UT27 links to [IEEE conference templates](https://www.ieee.org/conferences/publishing/templates). The direct `conference-template-a4.docx` download returned HTTP 202 with `x-amzn-waf-action: challenge` and no document. The challenge was not bypassed.

The retained unmodified file was retrieved from the [IEEE A4 template mirror on the CISS 2025 conference site](https://www.ciss2025.cn/assets/template/conference-template-a4.docx). Only the IEEE template file was used; CISS submission rules were not imported. The file uses Strict OOXML. Its original three pages were rendered and visually inspected.

The source styles, numbering and theme are preserved byte-for-byte in the English DOCX. The new body contains one author, two full-width figures and a native table. Sample authors, instructions, funding footnote and copyright placeholder text were removed. The source's A4 body geometry is top 54 pt, bottom 72 pt, side margins 45.35 pt, two columns with 18 pt gutter, a 24 pt title and 10 pt body.

Following the user's format review, the final abstract uses a single column, a 20 pt title and 11 pt body, without a separate short abstract or numbered full-paper sections. The original page dimensions and margins remain. UT27 specifies the IEEE double-column requirement for the later 4–10-page full paper; it does not explicitly mandate that column layout for the two-page abstract. This is an abstract-specific adaptation, not a claim of strict conformity to every original IEEE sample layout property.

Times New Roman is requested in DOCX. It is unavailable in the local renderer, which uses metric-compatible Liberation Serif and embeds it in the PDF. The rendered PDF therefore must not be described as containing Times New Roman. Template and preserved-part hashes are in `../template_preservation.json`.
