# UUV-SIM: MuJoCo 기반 통합 수중로봇 시뮬레이션 플랫폼의 설계 및 구현

강현민 | 국민대학교 미래모빌리티학과

수중로봇 개발에는 유체력과 접촉 동역학뿐 아니라 실제 제어기, 센서, 수중 영상을 함께 시험할 수 있는 환경이 필요하다. 본 연구는 MuJoCo를 수중로봇 개발에 활용하기 위한 구체적인 통합 방법을 제시하고, UUV-SIM 플랫폼을 설계·구현하였다. 초기 요구사항은 대회용 ROV 개발에서 도출하였으며, 제어 시험에서 실물 로그 비교와 학습용 데이터 수집까지 이어지는 재사용 가능한 연구 환경으로 확장하였다. 특정 GPU에 대한 의존도를 낮추고 계산 부담을 조절할 수 있는 구조를 목표로 MuJoCo를 선택하였다.

UUV-SIM은 MuJoCo의 강체·접촉 계산과 타원체 기반 유체력 근사를 활용한다. CAD를 반영한 8추진기 로봇에 부력과 복원 토크, PWM-추력 변환을 연결하고, 공간적으로 분산된 부력·항력과 6×6 부가질량 행렬을 지원하는 모델도 선택할 수 있도록 구성하였다. 로봇에 같은 유체력을 중복 적용하지 않도록 기본 모델과 사용자 정의 모델의 계산 담당 범위를 구분하였다. 수영장과 테스트 수조에는 부표, 관절형 줄, 자석 분리 및 로봇 접촉을 포함하여 임무 시험에 필요한 상호작용을 구현하였다.

실제 로봇에 사용하는 ArduSub 제어 환경을 유지하기 위해 SITL을 ROS 2·MAVROS 및 MuJoCo와 폐루프로 연결하였다. 조종 명령을 받은 SITL이 센서 피드백으로 PWM을 계산하고, 추진기 출력이 로봇 운동과 다음 센서 관측으로 돌아온다. 물리 계산, 제어기용 센서 전달, ROS 관측 발행 주기를 분리하고, 좌표계·단위·타임스탬프·토픽 발행 주체를 명시하였다. 이 구조를 통해 제어 소프트웨어와 물리 모델의 상호작용을 같은 실행 환경에서 시험할 수 있다.

관측 환경은 DVL, IMU, 압력 기반 수심과 전방·손 카메라로 구성하였다. 영상에는 픽셀별 수중 광선 거리에 따른 색 감쇠와 산란을 적용하고, 수면 일렁임과 윤슬을 근사적으로 표현하였다. 해상도·센서 발행률·광학 설정을 조절할 수 있으며 웹 GUI의 미리보기는 원본 센서 발행과 분리하였다. 화면을 보기 좋게 만드는 효과와 물리 힘 계산을 구분하고, 광학 계수는 실측 보정 전의 가정으로 관리한다.

VLA 연결을 위해 두 카메라 영상, 23차원 상태, 4차원 조종 행동을 시뮬레이션 시간 기준으로 수집한다. 오래된 센서 입력과 시계 역행을 검사하고, 출처 및 종료 사유를 기록한다. 수집 결과는 LeRobot 형식과 U0 입력 전처리로 연결하였다. 비무장·중립 입력의 연결 검사에서 51개 표본을 기록하고 36개의 완전한 16단계 행동 청크를 실제 로더로 읽었다. 이는 데이터 인터페이스의 작동 근거이며, 작업 시연 학습이나 정책의 실물 전이 검증은 아니다.

계산 효율은 기존 구현과 동일한 조건에서 평가하였다. 105개 샘플의 잠김·물살 조회를 일괄 처리하면서 유체력 수식을 유지한 결과, 독립적인 힘·토크 평가 시간이 약 2.65 ms에서 0.47 ms로 줄었다. 1,500개 연속 물리 스텝 비교에서는 해당 시험 궤적의 힘·토크 및 위치 차이가 검출되지 않았다. 이 결과는 구성 요소 최적화의 효과이며 다른 엔진 대비 우월성이나 전체 시스템의 실시간 실행을 의미하지 않는다.

Real2Sim은 실물 조종 명령의 폐루프 재생으로 보정한다. 최신 응답 보정에서 전진 속도 RMSE는 실험 A에서 0.505→0.0436 m/s, B에서 0.303→0.0298 m/s로 각각 91.4%, 90.1% 감소했다(그림 3). 시간 보정 모델 대비 회전 명령 해제 구간의 각속도 RMSE도 각각 6.12→3.85°/s, 7.07→4.71°/s로 줄었다. 다만 B의 전체 구간 yaw 각도 RMSE는 2.51→5.75°로 증가했다. 두 기록 모두 개발에 활용했으므로 독립적인 최종 시험이 아닌 보정 검사 결과다. 실제 ESC 전압과 일부 모델 계수의 불확실성도 남아 있다.

본 연구의 기여는 MuJoCo에서 수중 물리, SITL 제어, 관측 및 데이터 수집을 연결하는 실행 가능한 플랫폼을 구현한 데 있다. 공개 코드와 설치·설정·검증 도구를 제공하여 다른 로봇과 시험 시나리오로 확장할 수 있는 기반을 마련하였다. 현재 통합 배포의 지원 기준은 Ubuntu 22.04와 ROS 2 Humble이다. 향후에는 추가 실물 조건으로 보정을 확장하고 작업 시연을 수집하여 VLA 정책 학습과 전이를 평가할 계획이다.
