# 2026.09.08-pre-vla

VLA 적용 전 기본 ROV 실행·통신·시뮬레이션 소스 기준 버전입니다.
최신 소스 브랜치는 `main`입니다. 기존 ZIP/DEB 설치 파일을 새로 만든 릴리스는 아닙니다.

## 정리한 내용

- `ros2 launch auv rov_start.launch.py` 진입점을 추가했습니다. 기존
  `hit25_auv_ros2` 구현과 실행 인자를 유지하며, 모든 실행 파일의 이름을 바꾼 것은 아닙니다.
- strict 시뮬레이션 MAVROS 설정에 `setpoint_raw`, `vision_pose`,
  `vision_position_delta` 경로를 포함했습니다. 조직 MAVROS의 DVL 플러그인을
  별도 패키지로 제공해 일반 MAVROS 설치에서도 같은 메시지를 전달합니다.
- 기본 FCU 메시지 요청 주기를 ATTITUDE/RAW_IMU 50 Hz,
  LOCAL_POSITION_NED 20 Hz, SCALED_PRESSURE2 10 Hz로 맞췄습니다.
- 컨트롤러의 기본 RC 출력은 실물과 같은 `/mavros/rc/override`입니다.
  RC mux는 여러 제어기를 명시적으로 연결할 때 사용하는 선택 구성입니다.
- FCU 물리 교환을 400 Hz 기준으로 처리하고, 외부 ROS 발행 주기와 분리했습니다.
  도착한 PWM과 센서 측정값을 물리 단계에 반영해 제어 경로의 불필요한 대기를 줄였습니다.
  센서의 모델링된 잡음과 전달 지연은 유지합니다.
- T200 추진기 모델, 센서 전달·DVL·카메라 관련 현재 작업을 함께 포함했습니다.
  깨진 호밍 도구 링크와 최신 소스 참조를 정리하고, 개인 환경 설정 및 자동 생성
  검사 결과를 소스 추적에서 제외했습니다.

## 검증 범위

기본 ROV ROS 패키지 빌드와 인터페이스 검사, FCU 갱신·센서 전달·추진기
회귀 검사를 수행했습니다. 격리된 MAVROS/가상 FCU 검사에서는 RC override,
위치 setpoint, vision pose, DVL delta가 실제 MAVLink 메시지로 전달되는 것을
확인했습니다. ROS ENU 위치 `(1, 2, -3)`은 NED `(2, 1, 3)`으로 변환되었고,
DVL 속도 0.2 m/s를 0.1 s 적분한 이동량 0.02 m가 전달되었습니다.
arm/mode 서비스 존재를 확인했으며 실제 기체를 작동시키지 않았습니다.

앞선 MuJoCo+ArduSub 폐루프 재현에서는 동일 PID에서 yaw 각속도 RMS가
125.27 deg/s에서 약 0.40 deg/s로 감소했습니다. 이는 해당 시뮬레이션
재현 조건의 결과이며 실물 성능이나 GUI 부하 상태 전체를 보증하지 않습니다.

## 남은 한계

- 사용자 요청에 따라 실물 ROV 실행 검증은 보류했습니다. 기본 인터페이스
  정합성과 시뮬레이션 검증을 실물 검증 완료로 해석하면 안 됩니다.
- 실물 센서 잡음·지연, 추진기 동특성, 수중 카메라 보정과 장착 좌표는
  측정 후 보정해야 합니다. 현재 미검증 사전값은 실측값이 아닙니다.
- 대회 알고리즘과 조직 최신 mission handshake 전체 동기화는 범위 밖입니다.
- VLA는 아직 적용하지 않았습니다. 이 버전은 적용 전 비교 기준입니다.

조직 원본 및 실행 경로는 [기본 ROV 인터페이스](../contracts/REAL_STACK_PARITY.md),
소스 관리 기준은 [Git 게시 정책](../GIT_PUBLISHING.md)을 참고하세요.

## 게시 시 검사 결과

- ROS 패키지 `auv`, `hit25_auv_ros2`, `auv_mavros_dvl_plugin`,
  `auv_buoy_vision_control` 빌드 통과.
- 기본 ROV 기능 CTest 7개와 직접 RC/카메라 기본값 검사 3개 통과.
- 런타임 전체 단위 검사 370개 중 359개 통과, 11개 미통과.
  미통과 항목은 `test_althold_throttle_normalization`의 별도
  `ardupilot_sub_stable` 소스에 대한 사용자 패치 기대 5개,
  `test_pinger_homing_launch_parameters` 4개, `test_web_gui_runtime_contracts`의
  대회 제어기 관련 2개입니다. 전체 검사 통과 릴리스로 표시하지 않습니다.
- 패키지 전체 코드 스타일 검사는 flake8, pep257, uncrustify 미통과 항목이
  남아 있습니다. 기능 검사와 별도로 추적하며, 이번 변경에서 발견된 미사용
  launch 지역 변수 2개는 제거했습니다.

미통과 검사는 숨기거나 삭제하지 않았습니다. 대회 경로와 별도 펌웨어 패치의
정합성은 이 기본 ROV 소스 기준을 확장할 때 별도로 해결해야 합니다.
