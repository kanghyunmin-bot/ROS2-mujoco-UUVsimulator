# 2026.09.22 · VLA/PPO research source snapshot

[Visual implementation report](../UUV_UPDATE_20260922.md)

## Publication scope

Includes existing local simulator, collection FSM, sensor/recording guards,
U0 training/serving adapters, residual PPO and GUI implementation, their tests,
and documented September 15–22 changes. This is not a model-weight release.
Original demonstrations, real bags, entire rollout directories, environment
packages, runtime logs and mutable `RUNTIME_VERSION.json` are excluded.
Unrelated paper drafts and handoff notes are not included.

Fresh clones require the separately prepared U0/GR00T environment and local
checkpoints. Research tools currently refer to a host-local interpreter and the
upstream checkout under `outputs/vla-transfer-audit-20260910/upstream/auv_vla`.
The repository does not include that upstream tree or automatically provision
trained models. See collector and VLA GUI READMEs before attempting RL.
