# 2026.09.12 source snapshot — ROV VLA collection and research pool

이번 소스 갱신은 연구 수영장, 전방·손 카메라, VLA 수집·정책 어댑터와 실물 로그 기반의 제한적 보정을 통합합니다. GitHub 릴리스나 배포 DEB는 만들지 않았습니다.

## 변경

- 10×5×5m 연구 수영장, 3개 부표, CAD 기반 센서 배치 및 충돌 형상.
- 전방·손 카메라 역할 분리와 보정 설정, 실물 bag 참고 수조 라이너 재질.
- 분산 물살 조회 배치 계산으로 동일 물리식의 연산 비용 감소.
- 15N 자석 분리와 6관절 줄 접촉. 접힌 줄의 수치 발산을 재현하고 관절 안정화 관성을 조정.
- ROS 시간 기준 10Hz 수집, 상태23/행동4, 출처 및 종료 이유 기록, LeRobot/U0 입력 연결.
- RC 단일 발행자·잘못된 센서 시각·중복 영상·시간 역행·마지막 청크 처리 검증.
- Pinger Homing/Mission Check UI 숨김, 최신 장면 PNG/GIF/MP4.
- 개발 Docker 기반을 로컬 전용 이미지에서 공개 ROS Humble 이미지로 변경.
- 기본 프로파일과 분리한 단일 bag 수평 응답 보정 프로파일.

## 확인된 범위

- 수집·정책 ROS 시험 37개 통과.
- 실제 U0 환경 입력 시험 5개 통과. 50행 정지 수집에서 패딩 없는 16행동 청크 35개 전달.
- 접힌 줄 합성 재현: 이전 1.274초 후 발산, 수정 후 60초 경고 없음.
- 자석 하중, 부표 상승, 줄 굽힘·처짐·로봇 접촉, native 줄 항력 검사 통과.

상세 원인·제약은 docs/contracts 및 docs/gui의 날짜별 보고서를 참고하세요. 해당 보고서의 outputs 경로와 원본 실물 bag은 공개 소스에 포함하지 않습니다.

## 호환성과 한계

Ubuntu 22.04 / ROS 2 Humble / Linux x86_64 기준입니다. Ubuntu 24.04 호스트에서는 Docker를 사용합니다. NVIDIA GUI에는 NVIDIA Container Toolkit 및 디스플레이 설정이 필요합니다. Windows/macOS/ARM 전체 호환을 주장하지 않습니다.

Git LFS 모델과 ArduPilot submodule은 별도 다운로드가 필요하므로 `git clone --recurse-submodules`, `git lfs pull`을 사용하세요. 새 PC에서는 setup 절차를 실행합니다. 작업공간 절대 경로, Python 환경, 로컬 USB 권한을 복사하지 마세요.

카메라 기본 4Hz GUI 모니터링은 10Hz 작업 수집 조건을 충족하지 않습니다. 수집 시 카메라 유효 프레임률을 따로 확인해야 합니다. 제공 미디어는 정적인 물리 상태의 카메라 이동 프리뷰입니다.

학습된 ROV 정책, 유효한 작업 시연 학습 성공, 실물 전이는 미검증입니다. 줄 armature와 유체·센서 파라미터는 실측 인증이 아닙니다. 단일 실물 bag 적합 결과는 다른 작업으로의 일반화를 보장하지 않습니다.

## 게시 직전 추가 확인

수집·정책 37개, 물리/카메라/장면 pytest 9개 및 subtest 5개 통과. Git index에서 별도 경로로 추출한 소스에서도 자석·줄 동작과 유체 소유권 검사를 통과했다. 로컬에만 있던 CAD 자산을 소스에 포함하고 기존 YOLO 파일 한 개의 LFS 포인터 불일치도 정리했다. 새 GitHub CI에 ROS 없는 물리·카메라 계약 검사를 추가했다.

공개 ROS Docker 이미지에서 초기 빌드 시 ROS apt 저장소 키 설정 충돌을 재현했다. 기존 ROS 저장소 설정이 있으면 중복 등록하지 않도록 설치 스크립트를 수정했다. 상세 컨테이너 검증 결과는 개발 컨테이너 README에 기록한다.

공개 ROS 기반 Docker 빌드 및 새 컨테이너의 rclpy/MAVROS/NumPy/OpenCV import 검사가 통과했다. 소스 커밋 `05dc172`의 GitHub Source checks도 통과했다. 다른 PC의 GPU GUI와 전체 설치 과정까지 실기 검증한 것은 아니다. GitHub 릴리스·태그·새 DEB 배포는 만들지 않았다.
