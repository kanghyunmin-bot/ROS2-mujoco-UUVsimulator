# 센서 오차 모드 — 수학적 모델

## 범위와 GUI

웹 GUI의 기본 환경은 Research pool · distributed physics다.
일반 화면에서는 이 환경만 표시하고, 고급·비교 환경 표시를 켜면 기존 프리셋을
선택할 수 있다. 이미 선택한 비교 환경은 고급 표시를 꺼도 숨겨서 바꾸지 않는다.
환경 파일과 기존 CLI 선택지는 유지한다.

센서 오차 선택은 물리·장면·광학 설정과 독립적이다. 실행 중에는 변경할 수 없고,
다음 시작에 적용한다. 카메라 설정 변경에 따른 재시작도 마지막 적용 모드를 유지한다.

| 선택 | 의미 |
|---|---|
| 기존 센서 설정 | 기본값. 현재 수학적 센서 모델과 명시적인 환경변수 설정을 유지한다. 무오차가 아니다. |
| 수학적 오차 · 가정값 | 기존 IMU/Bar30/A50 수학 모델을 고정 프로필·seed로 선택한다. 하드웨어 보정 완료를 뜻하지 않는다. |
| 4월 bag · 압력 부분 보정 (2 Hz) | 압력 변동과 당시 2 Hz 출력 주기만 부분 보정했다. 다른 항목은 가정값이다. |

명명된 두 모드는 센서별 환경변수 override를 제거하고 해당 프로필을 적용한다.
기존 모드는 override를 그대로 유지한다. 제거된 override, 적용된 override,
프로필 전문, SHA-256을 실행 설정에 기록한다. 원래 부모 프로세스 환경은 수정하지 않는다.
레코더가 저장하는 context.json의 simulation.active_sensor_error에 이 정보가 포함된다.
이는 실행 요청 설정의 증거이며 실제 출력 주기나 FCU 파라미터 readback은 아니다.

## 재사용한 수학 모델과 단위

새로운 노이즈를 기존 출력에 중첩하지 않는다. 기존 bridge의 모델을 그대로 한 번 적용한다.

IMU 측정은 축별 scale/cross-axis 행렬, 일정 bias, 시작 bias, Gauss–Markov bias,
random walk, 백색잡음을 합성하고 포화·양자화를 적용한다.

- Gyro 단위: rad/s. 가속도 단위: m/s².
- Gauss–Markov 갱신: b[k+1] = phi b[k] + sigma sqrt(1-phi²) z,
  phi = exp(-dt/tau), z는 표준정규 변수.
- Random walk 갱신: w[k+1] = w[k] + q sqrt(dt) z.
  q 단위는 각각 (rad/s)/sqrt(s), (m/s²)/sqrt(s).
- IMU 잡음 밀도 N은 이상적인 Nyquist 대역폭 가정 아래
  표준편차 N/sqrt(2*샘플주기)로 변환한다.
- Bar30는 압력 [Pa]의 offset, scale, drift, 온도 응답, 잡음, 포화·양자화로 계산한다.
  압력 잡음은 해당 출력 프로필의 샘플당 표준편차이며 IMU 잡음 밀도와 다르다.
- DVL은 빔 기하, 범위, 유효성, 측정 오차를 거쳐 속도를 얻는다.
  측정 속도를 modeled gyro 기반 자세로 좌표 변환해 적분한다.
  위치 정답을 읽어서 추정 위치를 복사하거나 임의 위치 오차를 더하지 않는다.
  bottom lock이 없으면 위치 적분을 멈추고 불확실성은 증가한다.

누적오차는 DVL의 장치 적분 항법 및 FCU 추정 경로에서 발생한다.
이 구현이 실물 Pixhawk의 모든 EKF 오차를 재현한다는 뜻은 아니다.
IMU의 직접 출력 quaternion에는 별도의 관측 prior가 존재한다.
이를 실제 FCU 추정 자세 또는 gyro 적분 결과와 동일하다고 해석하지 않는다.
VLA는 /mavros/imu/data 및 data_raw의 실제 연결 경로를 사용한다.

## 시간·주입 위치

캡처·장치 시계·도착 시각·전송 큐가 분리된 기존 수학 모델을 사용한다.
IMU 캡처의 gyro/accel 및 압력 캡처는 FCU 방향 입력에 반영한다.
ROS 전송 지연·패킷 손실은 이미 FCU가 소비한 캡처를 삭제하지 않는다.
같은 seed/입력/캡처 일정이면 reset 후 재현된다.
시계 역행은 runtime reset, 큰 시간 점프는 존재하지 않은 과거 캡처를 생성하지 않는
기존 동작을 유지한다.

시간 구조를 임의로 바꾸거나 작업 단계에 맞춰 결측을 주입하는 novelty 실험은 추가하지 않는다.
프로필의 상관시간·지연 중 실측하지 않은 값은 engineering prior이며,
bag에서 식별한 값으로 재명명하지 않는다. 시간에 따른 drift 자체의 수학적 모델은 유지한다.

## bag 근거와 제한

기존 numeric.npz의 SHA-256을 확인했다:
690005e395930eaa086bb8c834867bd1d521935f0dbc3a552bf70b674411bd0b

기존 pressure_fit.json과 프로필이 일치한다:
90–115 s의 50개 샘플로 압력 변동을 추정했고, 같은 세션의 115–140 s
50개 샘플을 별도 확인에 사용했다. 압력 white scatter는 24.02025008830701 Pa.
수면 운동·진동·필터 영향이 섞여 있으므로 순수 하드웨어 잡음 식별이 아니다.
같은 세션의 인접 구간은 독립 실물 검증이 아니다.

2 Hz 프로필을 10 Hz로 바꾸고 같은 잡음값을 쓰면 동일한 bag 재현이라고 할 수 없다.
이 모드는 VLA 10 Hz freshness 검사를 통과시키기 위한 설정이 아니다.
IMU·DVL의 장기 drift, 지연, cross-axis 오차는 이 bag으로 검증하지 않았다.

## 확인 및 남은 범위

- 모드 설정을 실제 IMU/Bar30/A50 로더로 읽는 테스트.
- 명시적 override 보존/교체, physics·optics 보존, 증거 snapshot 검증.
- 기존 수학 모델, 타이밍 큐, reset, 결측, 측정 속도 적분 테스트.
- 웹 기본 환경/고급 선택 유지, 오차 선택 유지, 실행 중 잠금 테스트.
- 전체 ROS/SITL/VLA 폐루프와 실물은 이번 오프라인 검사 범위 밖이다.
- 새로운 dependency, 학습 기반 오차 생성기, 임의 시간 구조 실험을 추가하지 않았다.
