# Experiments

This folder separates evidence from runtime code.

- `baselines`: named golden-master baselines and their commands.
- `runs`: generated run outputs.
- `legacy`: old debug runs retained for provenance.
- `paper_evidence`: overlays, tables, and source metadata intended for writing.

Generated run folders should include a short `README.md` or metadata JSON with:

1. command,
2. git status summary,
3. input bag or CSV source,
4. generated CSVs,
5. generated overlays,
6. acceptance/rejection note.
