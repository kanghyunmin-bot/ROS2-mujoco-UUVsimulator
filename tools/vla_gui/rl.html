VLA 고정 · 보정 정책 PPO 학습

시작을 누르면 별도 시뮬 환경에서 카메라 관측 → VLA → 보정 행동 → 보상 → PPO 업데이트를 반복합니다. 초기 평가 후 학습·현 기준 정책 재평가·후보 평가를 반복하며, 평가에서 분리 등급별 누적 건수가 악화된 후보는 되돌립니다. 평가는 PPO 학습 데이터에 넣지 않습니다. 물리·통신 오류 환경은 해당 실행에서 제외하고 나머지는 계속 학습합니다. 오류 시도는 학습·성공 통계에서 제외하며, 환경 3개에서 오류가 나거나 모델별 남은 환경이 없으면 중단합니다. 기존 조종 화면과 분리해서 실행합니다. 원본 VLA는 유지하고 보정 정책을 별도 저장합니다.

우측 포크 영역 기준 보기

기체 FLU 좌표 기준 중심: 전방 33.55cm, 우측 9.19cm, 아래 10.43cm. 상자 크기: 전후 8cm × 좌우 5cm × 높이 5cm. 기체와 함께 회전·이동합니다. 분리 순간 봉 중심선과 상자가 겹치면 영역 등급입니다. 실제 접촉·배타적 원인 증명은 아닙니다.

개념도이며 실물 비례가 아닙니다. 크기는 초기 설정으로 실제 끼움 영상과 추가 검증이 필요합니다.

설정한 제한 시간 이내 실제 결합 해제는 일반 분리로 집계합니다. 분리 직전 0.25초 이내 손 카메라 여러 대표점의 시야·가림 판정에 목표가 확인되면 손 시야 등급, 분리 순간 하부 봉의 중심선이 우측 포크 틈 영역과 겹치면 포크 등급입니다. 손 시야는 기하학적 대리 판정이며 픽셀 인식 결과가 아닙니다. 세 등급의 종료 점수는 중복 합산하지 않습니다. 성공 기록은 보존하고, 실패 경험도 정책 학습에 활용합니다.

접근은 시도 내 최단 거리 개선에만 보상하고, 분리 전 우측 포크와 봉의 실제 접촉은 한 번만 보상합니다. 접촉만으로 성공 처리하지 않습니다. 빠른 성공은 남은 시간 비율에 따라 추가 보상합니다. 높이 정렬은 거리까지 반영해 해당 시도에서 최고 정렬도를 개선할 때만 보상합니다. 깊이 또는 yaw를 바꾼 뒤 목표를 재발견하면 시도당 한 번 보상합니다. 회전·깊이 변경 자체나 카메라 끊김에는 보상하지 않습니다. 재발견은 시뮬의 카메라 시야·가려짐 판정으로 계산합니다. 보상값은 성능 조정이 필요한 초기값입니다.

우측 포크 영역 분리 비율

보상 상승이 실제 성공률 상승을 뜻하지는 않습니다. 선은 회차 평균이며 세 비율의 분모는 해당 회차의 전체 저장 시도 수입니다. 차이가 작은 후보는 최고 모델을 교체하지 않고 학습만 이어가며, 등급별 성과가 줄거나 평균 보상이 0.25 이상 하락하면 되돌립니다. 변경이 없는 정책은 평가하지 않고, 변경 후보는 현 기준 정책을 같은 초기 배치와 추론 시드로 다시 실행하여 비교합니다. 보상 차이 0.25 미만만으로는 채택하지 않습니다. 소수 평가의 통과는 일반화 성능 보증이 아닙니다. 등급은 서로 중복되지 않으며, 과거 등급 미기록 시도는 임의 분류하지 않습니다.
