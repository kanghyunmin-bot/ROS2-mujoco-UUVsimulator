# VLA GUI 실행

호스트에서 `bash docker/ubuntu-dev/dev.sh web`을 실행하면 기존 GUI(8878)와
VLA 관리 서버(8882)가 함께 시작됩니다. 기존 GUI의 오른쪽 아래
**VLA 모델 선택 · 실행** 패널을 여세요.

1. 시뮬을 시작하고 비교할 로봇·부표 시작 위치를 설정합니다.
2. 강조 설정과 추가 학습량을 고르고 **모델 준비**를 누릅니다.
3. 실제 준비 모델과 예열 완료를 확인하고 **ARM 후 실행**을 누릅니다.
4. 종료 후 결과와 DISARM/수동 복귀 메시지를 확인합니다.

패널은 기본/중간/강한 강조 × 추가 2만/4만/6만 체크포인트를 지원합니다.
완료된 포크 정렬 중간 2배 추가 5,000/10,000스텝 모델도 표시합니다.
최신 10,000스텝 모델이 있으면 초기 선택값으로 사용하고 해당 학습 지시문을 채웁니다.
사용자가 직접 수정한 지시문은 모델 변경 시 덮어쓰지 않습니다.
실제 모델은 준비 완료 전에는 로딩되지 않습니다.
기존 저장된 시연으로 예열하며 이 단계는 로봇 명령을 발행하지 않습니다.
실행 버튼은 STABILIZE 전환, ARM 확인, GUI RC 제어권 전환, 정책 실행을 수행합니다.
시뮬 프로세스가 없는 경우 ARM 전에 거절합니다. 실물 운용용이 아닙니다.

실행 결과와 모델/예열/정책 로그는 `outputs/vla-gui/`에 남습니다.
`정밀 접근 최고 관측 후보 · PPO v3 · 근접 점수 0.856`은
`20260922-155955-6c1b18/release-best/collection-00059.pt` 잔차 정책을
동결된 135개 시연 VLA와 함께 실행합니다. 해당 로컬 파일과 기본 모델이 모두
있을 때만 표시됩니다. 0.856은 평가 중 한 시도의 기하학적 삽입 근접 점수이며
성공률이 아닙니다. 해당 평가의 일반 분리는 3/4, 포크 영역 분리는 0/4입니다.
기존 기본 선택 모델은 바꾸지 않으며 이 후보는 실행 화면에서 직접 선택합니다.
`일반 분리 최고 평가 후보 · PPO v3 · 분리 4/4`는 같은 실행의
`precision-candidate/collection-00035.pt`를 사용합니다. 일반 분리 평가는
4/4였지만 손 시야·포크 영역은 0/4이고, 손 시야 성적 하락으로 종합 승인은
받지 못한 후보입니다. 정밀 성공이나 일반화 성능이 검증된 모델은 아닙니다.
`detached`는 시뮬 분리 상태 감지이며 실제 로봇의 성공을 뜻하지 않습니다.
이 실행기는 기존 `run_rollout.py`의 120초 wall-clock 한도와 센서/명령 watchdog을
유지합니다. 시뮬 진행 속도에 따라 요청한 시뮬 시간에 도달하기 전 끝날 수 있습니다.

관리 서버는 정확히 이 저장소를 `/workspace`에 마운트한 개발 컨테이너 하나를 찾습니다.
컨테이너 이름을 하드코딩하지 않습니다. 모델 준비 시 requirements-ros.txt를 확인/설치합니다.
기존 이 저장소의 serve_transfer.py 서버는 정리하지만, 무관한 8000 포트 사용자는
종료하지 않고 오류를 표시합니다. 같은 관리 서버에서 모델을 바꾸면 이전 모델을 정리합니다.

호스트 GPU 환경은 `/home/khm/miniforge3/envs/gr00t/bin/python`을 사용합니다.
다른 PC에서는 server.py의 PYTHON을 해당 환경에 맞춰야 합니다.
GUI를 다른 방법으로 시작한 경우 호스트에서 `bash tools/start_vla_gui.sh`를 실행하세요.

검사: `python3 -m unittest discover -s tools/vla_gui -p 'test_*.py'`

## 연구 GUI를 18879 포트에서 사용할 때

`bash tools/start_research_gui.sh`는 설치된 ROS 개발 이미지로 연구 GUI를 실행합니다.
브라우저에서 `http://127.0.0.1:18879/`를 열고 시뮬 시작을 누릅니다.
ARM과 수동 입력은 별도로 켭니다. `stop`, `status` 인자로 종료와 상태 확인이 가능합니다.
기존 컨테이너가 있으면 그대로 재사용하며, 새 컨테이너는 사용 가능한 GPU를 확인합니다.
GPU가 없으면 CPU 렌더링을 사용하지만, 실시간 영상이나 VLA 수집 성능을 보장하지 않습니다.
화면의 수신 시간과 촬영 지연을 함께 확인하세요. 수집기의 영상 신선도 제한은 유지됩니다.

관리 서버도 같은 GUI를 사용하도록 `UUV_GUI_URL=http://127.0.0.1:18879`를 설정하고
`python3 tools/vla_gui/server.py`를 실행합니다. 기본값은 기존 `http://127.0.0.1:8878`입니다.
ROS 명령은 발견한 컨테이너의 DDS 설정을 따릅니다.
YOLO는 컨테이너의 ROS Python 환경에 해당 비전 의존성이 설치되어 있어야 합니다.
